# The Barney Ecosystem

**Bring your own operating system.**

Barney is an independent, open-source engineering platform for building, composing and maintaining operating systems.

The goal is simple: give people the engineering machinery to build the systems they need, without prescribing what those systems should look like.

This organisation brings together the projects that make up the Barney ecosystem.

## Projects

### [Barney](https://github.com/barney-build/barney)
**The platform.**

The core engineering tooling and language for describing, building and composing operating systems.

### [bny-base](https://github.com/barney-build/bny-base)
**The reference collection.**

Reusable recipes and modules providing a starting point for building with Barney. Use them, adapt them or replace them with your own.

### [Pavee OS](https://github.com/barney-build/pavee-os)
**An example system.**

A practical operating system project built with the Barney ecosystem. It provides a proving ground for the platform, while demonstrating just one of the many directions it can take.
